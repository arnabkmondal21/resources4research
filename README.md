# resources4research
Hi there, Welcome! The main objective of creating this repository is to documment everything I found interesting and worth sharing related to research in the field of medicinal chemistry, drug discovery and cheminformatics. If you are a complete beginner in research, I just want to say that, from my little experiences with research, what I have realized is that, research is all about having a strong desire to make impactful contribution towards the betterment of human being no matter how small or big the contribution is, and you should have patience along with a open and curious mind. Best wishes on your journey!

N.B. While exploreing the resources, if you think there is an excellent resource out there (obviously, there are many) which is not included here, please send me a message along with the link and a short description about the resource(s) using this [form](URL) and I will include them so that others can be benefited as well!
